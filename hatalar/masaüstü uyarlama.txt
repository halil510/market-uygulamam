FAZ 3 — MOBİL-ÖZEL PAKETLERİ İZOLE ETME
═══════════════════════════════════════════════════════════════════════
Her paket için ayrı ayrı çalış, her birinden sonra DUR:

3.1) vibration
   - HapticFeedback ve Vibration.vibrate() çağrılarını bul.
   - lib/cekirdek/utils/titresim_utils.dart adında bir yardımcı oluştur:
     
     import 'dart:io';
     import 'package:flutter/services.dart';
     import 'package:vibration/vibration.dart';
     
     class TitresimUtils {
       static Future<void> hafif() async {
         if (Platform.isAndroid || Platform.isIOS) {
           HapticFeedback.lightImpact();
         }
       }
       static Future<void> orta() async {
         if (Platform.isAndroid || Platform.isIOS) {
           HapticFeedback.mediumImpact();
         }
       }
       static Future<void> vibrate({int ms = 50}) async {
         if (Platform.isAndroid || Platform.isIOS) {
           final has = await Vibration.hasVibrator() ?? false;
           if (has) Vibration.vibrate(duration: ms);
         }
       }
     }
   - Tüm doğrudan HapticFeedback/Vibration çağrılarını bu yardımcıyla değiştir.
   - Android davranışı BİREBİR AYNI kalmalı.

3.2) permission_handler
   - Sadece Android/iOS'ta gerekli. Platform.isAndroid kontrolü ekle.
   - Windows'ta izin isteme kodunu atla.

3.3) local_auth

3.4) mobile_scanner (kamera ile barkod)
