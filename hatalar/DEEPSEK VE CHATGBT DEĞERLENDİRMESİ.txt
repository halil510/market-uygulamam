3. Grup Bölme (Recursive Split) Yüzlerce HTTP İsteği Atabiliyor
Dosya: bulut_manager.dart, _upsertGrubuGonder

dart
if (sonuc.tur == BulutHataTuru.kalici && satirlar.length > 1) {
  return await bol();  // ikiye böl, iki yarıyı tekrar dene
}
Senaryo: 500 satır gönderdin. Sunucu 400 döndü (bir satırda geçersiz sütun var). bol() 250/250 çalıştırır. Bir tanesi yine 400 dönerse → 125/125. Bu log₂(500) ≈ 9 seviye demek. Worst case: ~18 HTTP isteği tek bir poison row için.

Daha kötüsü: 500 satırın TAMAMI poison ise (ör. yanlış sütun adı), 500 tane tek satırlık istek atılır, hepsi başarısız olur. Toplam: 999 HTTP isteği.

Düzeltme:

Bölmeyi sadece 2 seviye yap (500 → 250 → 125 → dur).

125 hâlâ 400 dönüyorsa → muhtemelen tüm grup bozuk, satırları tek tek değil, ilk 5'ini deneyerek pattern'i bul, geri kalanı atla.

Ya da en kötü senaryo için bir "max split depth" (ör. 3) parametresi ekle.

dart
Future<...> _upsertGrubuGonder(..., {int derinlik = 0}) async {
  ...
  if (sonuc.tur == BulutHataTuru.kalici && satirlar.length > 1 && derinlik < 3) {
    return await bol(derinlik: derinlik + 1);
  }
  // derinlik == 3 ise satırları tek tek değil, "kalici_hata" olarak işaretle
  // ve insan müdahalesi bekle.
  ...
}

4. _bekleyenSayisiCache++ Yarış Durumu
Dosya: bulut_manager.dart, _kuyrukaYaz

Task B: transaction başlar

Task A: biter, cache++ (cache = 1)

Task B: biter, cache++ (cache = 2) ✓

Sonra yeni bir upsert() cache++ yapar.

✅ Gerçekten İyi Olan Şeyler
Bunlara dokunma:

SyncKuyrukYazici.ekleTxn — delete-before-insert deseni. Aynı global_id için kuyrukta eski kayıt varsa silinir. Kuyruk şişmez, her zaman en güncel hali gider. Mükemmel.

Backoff mantığı saf fonksiyonda (sync_backoff.dart). Test edilebilir, DB'siz. Bu seviye ayrımı profesyonel iş.

Realtime'ın sadece "trigger" olması, veriyi yazmaması. Bildirim gelince mevcut güvenli hattan (FK çeviri, LWW, watermark) çekiyor. Bu endüstri standardı yaklaşım. Doğru.

kalici_hata vs gecici hatası ayrımı. 4xx → sonsuz deneme yok, insan müdahalesi bekler. 5xx/ağ → backoff ile sonsuz dene. Kitap gibi doğru.

Watermark (otoGonderZamaniYaz). Sunucu saati ile çakışma tespitinde kullanılıyor. Akıllı.

_isle() reentrancy guard (_gonderiliyor flag'i). Double-check await Veritabani().db sonrası. Doğru.

_veriCoz'da kredi_kartlari.kart_no_maskeli son-hal düzeltmesi. NULL/boş gelirse fallback. Sunucu 400 dönmesin diye.

upsert() içinde audit log kancası. Cloud yapılandırılmamış olsa bile audit çalışsın diye en başa konmuş. Düşünülmüş.

AnlikBulutDinleyici — Realtime'ın WebSocket protokolü doğru uygulanmış. phx_join, heartbeat, phx_reply, system mesajları hepsi doğru işleniyor.

_kaliciHatalariKuyrugaGeriAl — otomatik vs manuel. Otomatik 20 denemeden sonra durur, manuel tümünü sıfırlar. Doğru denge.
